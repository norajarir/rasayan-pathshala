# রসায়ন পাঠশালা · Chemistry Pathshala

উচ্চ মাধ্যমিক (HSC) ১ম ও ২য় বর্ষের শিক্ষার্থীদের জন্য একটি দ্বিভাষিক (বাংলা/English) ইন্টারঅ্যাকটিভ রসায়ন শেখার ওয়েবসাইট।

A bilingual (Bangla/English) interactive chemistry learning site for HSC (Class 11–12) students in Bangladesh.

## Features

- **১৯টি অধ্যায়ের নোট** — ১ম বর্ষ ১০টি, ২য় বর্ষ ৯টি। প্রতিটি অধ্যায়ে মূল ধারণা, দৈনন্দিন উদাহরণ, মনে রাখার মূল কথা এবং "আরও জানা ভালো"।
- **ইন্টারঅ্যাকটিভ পর্যায় সারণি** — ১১৮টি মৌল, ক্লিকে ভর, শ্রেণি, গ্রুপ, যোজনী ও ইলেকট্রন বিন্যাস।
- **৩ডি মলিকিউল ভিউয়ার** — পানি, মিথেন, CO₂, অ্যামোনিয়া, ইথানল, বেনজিন, গ্লুকোজ, NaCl (কোনো লাইব্রেরি ছাড়া, pure canvas)।
- **MCQ কুইজ** — প্রতি উত্তরে ব্যাখ্যা ও শতকরা ফলাফল।
- **রাসায়নিক সমীকরণ ব্যালান্সার** — Gaussian elimination দিয়ে যেকোনো সমীকরণ ব্যালান্স।
- **২৮টি বোর্ড প্রশ্ন ও ধাপে ধাপে সমাধান** — সার্চ সুবিধা সহ।
- **বাংলা ⇄ English** টগল।

## Structure
